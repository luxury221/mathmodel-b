## 2. 统一计分口径

对每个案例先算 `完整任务虚拟耗时 / 实际源数`，再对案例等权平均。不是把所有案例总时间除以总源数，也不是只统计最后一个源清除前的时间。

完整任务计入移动、测向、换频、成功/失败光学清除，以及最后清除后为确认搜索完成而发生的实际动作。任何未全清的运行均保留为失败，不从均值里剔除。

**程序CPU运行秒数、覆盖约束条数、求解器分支数、理论下界都不能当作秒/源成绩。**

## 5. 快速核验与本地复现

使用Python 3.12。Windows示例均将环境、缓存和输出放在D盘：

```powershell
cd D:\数模B题\mathmodel-b
. .\scripts\env.ps1
py -3.12 -m venv .venv
& $PythonExe -m pip install -r requirements-offline.txt
& $PythonExe scripts\verify_published_results.py --replay-offline
& $PythonExe -m pytest tests -q
```

运行当前算法的本地模拟：

```powershell
& $PythonExe scripts\run_offline_baselines.py --problem all --counts 13 --output D:\数模B题\mathmodel-b\outputs\offline_demo
```
