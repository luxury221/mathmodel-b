# 1. 总体建模思想

整道题不应拆成四套彼此独立的算法，而建议统一成如下主线：

\[
\boxed{
\text{鲁棒可行域估计}
\rightarrow
\text{主动观测选点}
\rightarrow
\text{动态路径规划}
\rightarrow
\text{保证性终局搜索}
}
\]

其中：

- **问题 1**：解决“多个含误差示向度如何形成定位区域、如何计算定位区域直径、何时能保证 20 m 内清除”；
- **问题 2**：解决“第一次检测后，第二个检测点放在哪里，才能在保证接收的前提下获得最好的几何定位效果”；
- **问题 3**：将全向源搜索建模为“每频道可行域逐步排除 + 覆盖路径保证 + 在线联合搜索定位”；
- **问题 4**：将定向源搜索提升为“位置—方向联合可行域 + 局部凸包保证定理 + 自适应快搜 + 保证性补搜”。

为了兼顾可靠性与速度，建议采用“双层架构”：

### 1.1 严格保证层
只使用题目明确给出的确定性信息，例如

\[
|\varepsilon|\le 1^\circ,
\quad
1000\le R_c\le1500,
\quad
r_{\rm clear}=20.
\]

所有“确保清除”的结论都建立在这一层，不依赖任何人为概率分布。

### 1.2 效率决策层
使用离散候选点、粒子假设、信息增益、路径代价等方法选择下一动作，使平均时间尽可能短。

效率层可以使用采样近似，但其作用只在于“加速”，不能替代保证层的正确性证明。

# 2. 统一符号与状态变量

目标区域：

\[
\mathcal D=\{(x,y):x^2+y^2\le1800^2\}.
\]

频道集合：

\[
\mathcal C=\{1,2,\ldots,20\}.
\]

每个频道最多对应一个干扰源。

对频道 $c$，维护状态

\[
z_c\in\{\texttt{UNKNOWN},\texttt{DETECTED},\texttt{LOCALIZED},\texttt{CLEARED},\texttt{ABSENT}\}.
\]

同时维护：

- 位置可行域 $F_c$；
- 已知测量集合 $\mathcal M_c$；
- 更高阶实现中维护接收半径可行区间、方向可行域和类型假设；
- 最小包围圆中心 $C_c$ 与半径 $R_c^{\rm MEC}$；
- 是否已有“可保证清除点”。

机器狗状态记为

\[
X=(P,h,t_v,t_r),
\]

其中 $P$ 为当前位置，$h$ 为测向机当前频道，$t_v$ 为虚拟时间，$t_r$ 为剩余现实运行时间。

# 3. 统一时间模型

一次从 $P_{k-1}$ 到 $P_k$ 的移动耗时为

\[
T_{\rm move}=\frac{\|P_k-P_{k-1}\|}{5}.
\]

一次 `/measure`：

\[
T_{\rm measure}
=
\frac{\|P_k-P_{k-1}\|}{5}
+5
+\mathbf 1(h_{k-1}\ne c_k).
\]

一次 `/clear`：

\[
T_{\rm clear}=
\frac{\|P_k-P_{k-1}\|}{5}
+
\begin{cases}
5,&\text{清除成功},\\
3,&\text{未发现目标}.
\end{cases}
\]

且 `/clear` 不改变当前测向频道。

总虚拟时间可写成

\[
T=
\frac{1}{5}\sum_k\|P_k-P_{k-1}\|
+5N_m
+N_s
+3N_f
+5N_c,
\]

其中：

- $N_m$：检测次数；
- $N_s$：频道切换次数；
- $N_f$：失败清除次数；
- $N_c$：成功清除次数。

由于

\[
1000\text{ m 移动}=200\text{ s},
\]

而一次检测仅约 $5\sim6$ s，因此整题最核心的优化原则是：

\[
\boxed{\text{优先减少移动距离，其次减少检测与切频道次数。}}
\]

# 4. 问题 1：含示向误差的交会定位模型

## 4.1 单次示向度对应的角锥

设第 $i$ 个检测点为

\[
S_i=(x_i,y_i),
\]

测得示向度为 $\theta_i$，误差界为

\[
\delta=1^\circ.
\]

则真实干扰源 $G$ 必满足

\[
\arg(G-S_i)\in[\theta_i-\delta,\theta_i+\delta].
\]

定义边界单位向量

\[
u_i^-=
\begin{pmatrix}
\cos(\theta_i-\delta)\\
\sin(\theta_i-\delta)
\end{pmatrix},
\quad
u_i^+=
\begin{pmatrix}
\cos(\theta_i+\delta)\\
\sin(\theta_i+\delta)
\end{pmatrix}.
\]

则任一点 $X$ 属于该角锥，当且仅当

\[
u_i^-\times(X-S_i)\ge0,
\]

以及

\[
u_i^+\times(X-S_i)\le0.
\]

每次示向度因此产生两个线性半平面约束。

## 4.2 多次测量的定位区域

设共有 $n$ 次有效测向，定位区域为

\[
P=\bigcap_{i=1}^nW_i,
\]

其中 $W_i$ 是第 $i$ 次测量对应的误差角锥。

由于所有 $W_i$ 都是凸集，$P$ 也是凸集。

当 $P$ 有界时，它是一个凸多边形。

---

# 5. 问题 1：定位多边形的计算

推荐使用半平面交算法。

## 5.1 稳健易实现版本

1. 生成所有 $2n$ 条边界直线；
2. 求任意两条边界线的交点；
3. 保留满足全部半平面约束的交点；
4. 对保留点做凸包；
5. 得到按逆时针排序的顶点

\[
V_1,V_2,\ldots,V_m.
\]

检测点数通常很少，因此即使采用 $O(n^3)$ 的简单实现也足够。

## 5.2 高级实现

使用标准半平面交：

\[
O(n\log n).
\]

若出现：

- $P=\varnothing$：说明测量数据或数值实现存在冲突；
- $P$ 无界：说明交会角不足，需要新增检测点。

# 6. 问题 1：定位区域直径

凸多边形的最大距离一定由两个顶点取得，因此

\[
\boxed{
D(P)=
\max_{1\le i<j\le m}
\|V_i-V_j\|
}.
\]

对于本题顶点很少，直接 $O(m^2)$ 枚举即可。

若希望论文体现算法优化，可采用旋转卡壳，将直径计算降至

\[
O(m).
\]

# 7. 问题 1：以定位区域直径为直径的圆能否覆盖定位区域？

一般不能。

设

\[
D=\operatorname{diam}(P),
\]

$R(P)$ 为 $P$ 的最小包围圆半径。

任何包含 $P$ 的圆都必须满足

\[
R(P)\ge\frac D2.
\]

因此存在“直径恰为 $D$ 的圆”覆盖 $P$ 的充要条件是

\[
\boxed{
R(P)=\frac D2.
}
\]

二维 Jung 定理给出

\[
\boxed{
\frac D2\le R(P)\le\frac D{\sqrt3}.
}
\]

等边三角形达到右端上界，因此“直径为 $D$ 的圆一定能覆盖”是错误的。

## 7.1 与清除操作的关键联系

题目规定距离目标不超过 $20$ m 即可清除，因此真正正确的“必成功清除”判据不是

\[
D(P)\le40,
\]

而是

\[
\boxed{
R(P)\le20.
}
\]

若最小包围圆中心为 $C_P$，在 $C_P$ 调用 `/clear` 即可严格保证成功。

这是问题 1 对问题 3、4 最重要的接口。

# 8. 最小包围圆算法

对凸多边形顶点集合 $V$，最小包围圆由以下两类情况决定：

1. 两个点构成直径；
2. 三个点决定外接圆。

实现可采用：

- Welzl 随机增量算法，期望 $O(m)$；
- 或由于 $m$ 很小，直接枚举所有二点圆和三点圆并验证覆盖。

竞赛代码中建议采用后者，简单可靠。

# 9. 问题 2：第一次检测后的鲁棒可行域

设第一次有效检测点为 $S_1$，示向度为 $\theta_1$，误差上界为

\[
\delta=1^\circ.
\]

由于返回 `direction`，真实干扰源满足

\[
5<\|G-S_1\|\le \rho\le1500,
\]

以及

\[
|\operatorname{wrap}(\arg(G-S_1)-\theta_1)|\le\delta,
\qquad G\in\mathcal D.
\]

严格真实可行域为

\[
\Omega_1=
\mathcal D\cap W(S_1,\theta_1,\delta)
\cap B(S_1,1500)
\setminus B^\circ(S_1,5).
\]

注意：由于减去了 $5$ m 内圆，$\Omega_1$ 一般**不是凸集**。因此后续需要凸性时，使用保守凸外包

\[
\boxed{
K_1=
\mathcal D\cap W(S_1,\theta_1,\delta)
\cap B(S_1,1500)
}
\]

即可。显然

\[
\Omega_1\subset K_1,
\]

所以基于 $K_1$ 得到的“保证接收”结论仍然严格成立，只是略保守。

# 10. 问题 2：第二检测点的严格候选区域

对于全向干扰源，为了不依赖未知有效接收半径 $\rho\in[1000,1500]$，第二检测点 $Q$ 应保证对所有可能目标位置都有

\[
\|Q-G\|\le1000,
\qquad \forall G\in K_1.
\]

因此定义稳健候选域

\[
\boxed{
\mathcal C_{\rm recv}
=
\bigcap_{G\in K_1}B(G,1000)
=
\left\{Q:\max_{G\in K_1}\|Q-G\|\le1000\right\}.
}
\]

它可以理解为：**所有半径 1000 m、能完整包住第一次可行域的圆，其圆心集合**。

## 10.1 候选区域一定非空

这是一个可以严格证明的重要结论。

$K_1$ 被包含在一个顶角仅 $2^\circ$、最大半径 $1500$ m 的扇形中。对该扇形内任意两点，最远距离不超过

\[
\max\left\{1500,\;2\cdot1500\sin1^\circ\right\}=1500.
\]

故

\[
\operatorname{diam}(K_1)\le1500.
\]

由二维 Jung 定理，$K_1$ 的最小包围圆半径满足

\[
R_{\rm MEC}(K_1)
\le\frac{1500}{\sqrt3}
\approx866.03<1000.
\]

于是最小包围圆中心必属于 $\mathcal C_{\rm recv}$，所以

\[
\boxed{\mathcal C_{\rm recv}\ne\varnothing.}
\]

因此对于问题 2 的全向源，**总能找到一个保证第二次仍可接收到信号的检测点**。

## 10.2 数值计算方法

$K_1$ 是凸集。若用保守凸多边形 $\widehat K_1\supset K_1$ 逼近，则

\[
\widehat{\mathcal C}_{\rm recv}
=
\bigcap_{V_j\in\operatorname{Vert}(\widehat K_1)}B(V_j,1000)
\]

即可严格保证整个 $\widehat K_1$ 被包含在半径 1000 m 圆中，因为对固定 $Q$，函数 $G\mapsto\|Q-G\|$ 在凸多边形上的最大值必在顶点取得。

# 11. 问题 2：严格 minimax 第二点模型

“定位效果较好”应定义成可量化目标，而不是只说“交会角接近 $90^\circ$”。

对候选点 $Q\in\mathcal C_{\rm recv}$，真实源 $G\in\Omega_1$，第二次测量误差 $e_2\in[-\delta,\delta]$，第二次读数为

\[
\theta_2=\arg(G-Q)+e_2.
\]

第二次观测后的严格位置可行域为

\[
P_2(Q,G,e_2)
=
\Omega_1\cap W(Q,\theta_2,\delta).
\]

若 $\|Q-G\|\le5$，模拟器返回 `near`，此时可直接清除，应把该分支的定位代价视为不超过 5 m。

定义最坏定位半径

\[
\Phi(Q)
=
\sup_{G\in\Omega_1,\ |e_2|\le\delta}
R_{\rm MEC}\big(P_2(Q,G,e_2)\big),
\]

则问题 2 的鲁棒最优点为

\[
\boxed{
Q^*=\arg\min_{Q\in\mathcal C_{\rm recv}}\Phi(Q).
}
\]

连续问题可用“候选域网格 + 局部连续优化”求解；论文中给模型，程序中用离散候选点即可。

# 12. 问题 2：线段近似、透镜候选与一个重要修正

为了获得直观解析图形，可将狭长的第一次可行域近似成中心测向线上的线段 $AB$，长度为 $L$。

保证第二次接收的候选域近似为

\[
B(A,1000)\cap B(B,1000),
\]

即透镜区域。

设

\[
M=\frac{A+B}{2},
\]

$n$ 为线段 $AB$ 的法向单位向量，则透镜上下两个交点为

\[
\boxed{
Q_{\rm lens}^{\pm}
=
M\pm
\sqrt{1000^2-\left(\frac L2\right)^2}\,n.
}
\]

它们最大化了候选点到第一次中心测向线的横向距离，因此是非常好的**几何初始候选点**。

若近似取

\[
A=5,\qquad B=1500,
\]

则 $L=1495$，横向距离为

\[
\sqrt{1000^2-(1495/2)^2}
\approx664.26\text{ m}.
\]

但代码复核发现一个必须修正的表述：

\[
\boxed{Q_{\rm lens}^{\pm}\text{ 并不等价于 minimax 最优点。}}
\]

原因是“最大交会角”与“减小第二站到远端目标的距离”存在权衡。对简化线段模型，用下一节的局部定位半径做代理目标，数值 minimax 解约为

\[
Q^*\approx(824.71,\ 572.78)
\]

（坐标轴取第一次测向线为 $x$ 轴，$S_1=(0,0)$），其最坏局部定位直径约为 $121.40$ m；而透镜尖点 $(752.5,664.26)$ 的对应值约为 $123.17$ m。

因此建议：

1. 用 $Q_{\rm lens}^{\pm}$ 产生低成本初始候选；
2. 再在 $\mathcal C_{\rm recv}$ 中做 minimax 数值微调；
3. 问题 3、4 再叠加移动时间，不直接照搬纯几何解。

# 13. 问题 2：两站交会局部误差公式的推导

设真实目标附近的位置扰动为 $\Delta x$。第 $i$ 条示向线到目标距离为 $r_i$，其法向量为 $n_i$。在小角度 $\delta$ 下，一个宽度为 $2\delta$ 的角锥在目标邻域可近似为条带

\[
|n_i^\top\Delta x|\le a_i,
\qquad
 a_i=r_i\tan\delta.
\]

令第一条测向线沿 $x$ 轴，第二条与第一条夹角为 $\alpha$，则可取

\[
n_1=(0,1),
\qquad
n_2=(-\sin\alpha,\cos\alpha).
\]

两个条带的交集是中心对称平行四边形。其四个顶点由

\[
n_1^\top\Delta x=\pm a_1,
\qquad
n_2^\top\Delta x=\pm a_2
\]

得到。枚举符号并取最长对角线，可得

\[
\boxed{
D_{\rm lin}
\approx
\frac{2\tan\delta}{|\sin\alpha|}
\sqrt{r_1^2+r_2^2+2r_1r_2|\cos\alpha|}.
}
\]

由于该平行四边形中心对称，其最小包围圆半径等于最长对角线的一半，因此

\[
\boxed{
R_{\rm lin}
\approx
\frac{\tan\delta}{|\sin\alpha|}
\sqrt{r_1^2+r_2^2+2r_1r_2|\cos\alpha|}.
}
\]

于是几何优化原则不是单独“追求 $90^\circ$”，而是同时：

\[
\boxed{|\sin\alpha|\text{ 大}}
\qquad\text{且}\qquad
\boxed{r_1,r_2\text{ 小}}.
\]

特别地，若 $r_1=r_2=r$ 且 $\alpha=90^\circ$，则

\[
R_{\rm lin}\approx\sqrt2\,r\tan1^\circ.
\]

若希望两次测向后局部模型已满足 $R_{\rm lin}\le20$，则约需

\[
\boxed{
r\le
\frac{20}{\sqrt2\tan1^\circ}
\approx810.20\text{ m}.
}
\]

这给出一个非常实用的在线规则：若能在离目标约 800 m 内形成接近正交的两次测向，通常已经接近一次 `/clear` 可保证成功的精度量级。

代码把该近似与“精确两角锥求交”进行比较：

| $r_1$ | $r_2$ | $\alpha$ | 精确直径/m | 线性近似/m | 相对误差 |
|---:|---:|---:|---:|---:|---:|
| 500 | 500 | 90° | 24.693 | 24.685 | -0.03% |
| 1000 | 1000 | 90° | 49.385 | 49.370 | -0.03% |
| 1000 | 800 | 60° | 63.025 | 62.967 | -0.09% |
| 1500 | 1000 | 30° | 169.562 | 168.845 | -0.42% |
| 1500 | 1000 | 10° | 521.516 | 500.763 | -3.98% |

因此在论文推荐使用的交会角阈值 $\alpha\ge30^\circ$ 区间内，该代理公式精度足以用于在线候选点排序；最终保证仍由精确角锥交与 MEC 判断完成。

# 14. 问题 2 与问题 3 的区别

问题 2 只问“定位效果好”，因此可以优先几何精度。

问题 3 的目标是总任务时间短，因此第二点不应只做几何最优，而应加入移动成本：

\[
\boxed{
Q_T^*
=
\arg\min_Q
\left[
\frac{\|Q-P_{\rm now}\|}{5}
+T_{\rm meas}
+\widehat T_{\rm future}(Q)
\right].
}
\]

因此：

- 问题 2：**几何最优选点**；
- 问题 3、4：**时间最优主动观测**。

这是论文中应明确区分的两层目标。

# 15. 高上限统一可行域：显式加入接收半径隐藏变量

# 20. 问题 3：7 点全域保证覆盖基线及完整证明

由于所有全向源的有效接收半径至少为 $1000$ m，只要检测点集合 $\{Q_i\}$ 满足

\[
\mathcal D\subset\bigcup_iB(Q_i,1000),
\]

则一个始终未被发现的频道在这些点全部得到 `no_signal` 后，必可判为不存在源。

采用

- 中心点 $Q_0=(0,0)$；
- 半径为 $a$ 的正六边形六个顶点

\[
Q_k=a\left(\cos\frac{(k-1)\pi}{3},\sin\frac{(k-1)\pi}{3}\right),
\quad k=1,\ldots,6.
\]

## 20.1 不能只检查圆周中点：覆盖半径的严格推导

由六折对称性，只需考虑扇区

\[
0\le\theta\le\frac\pi6,
\qquad 0\le r\le1800.
\]

在该扇区中，离点 $(r,\theta)$ 最近的候选中心只需比较原点和角度 $0$ 的外圈点。到两者的距离分别为

\[
r,
\]

以及

\[
d(r,\theta)=\sqrt{r^2+a^2-2ar\cos\theta}.
\]

对固定 $r$，$d(r,\theta)$ 随 $\theta$ 增大，因此最坏角度为 $\theta=\pi/6$。此时原点与外圈点等距的径向位置由

\[
r=d(r,\pi/6)
\]

得到

\[
r=\frac a{\sqrt3}.
\]

故整个目标圆的严格覆盖半径为

\[
\boxed{
R_{\rm cov}(a)=
\max\left\{
\frac a{\sqrt3},\;
\sqrt{1800^2+a^2-\sqrt3\,1800a}
\right\}.
}
\]

要求 $R_{\rm cov}(a)\le1000$，得到

\[
a\le1000\sqrt3
\]

及

\[
a^2-1800\sqrt3\,a+1800^2-1000^2\le0.
\]

第二式较小根为

\[
\boxed{
a_{\min}
=\frac{1800\sqrt3-\sqrt{4\cdot1000^2-1800^2}}{2}
\approx1122.9558\text{ m}.
}
\]

因此在“中心 + 正六边形”这一对称族中，可行区间为

\[
1122.9558\le a\le1732.0508.
\]

由于从原点开始、不回原点、按六边形相邻顶点访问时移动距离为

\[
L=6a,
\]

所以该对称族内的最短路线取最小可行半径。考虑数值裕量，推荐正式程序取

\[
\boxed{a=1125\text{ m}.}
\]

此时解析覆盖半径为

\[
R_{\rm cov}(1125)\approx999.111\text{ m},
\]

仍留有约 $0.889$ m 的几何裕量。

对应六外点总移动距离

\[
6a=6750\text{ m},
\]

移动虚拟时间为

\[
1350\text{ s}.
\]

若极端情况下 7 个站点均扫描全部 20 个频道，并采用交替升降序频道扫描，则每站检测/切换约

\[
20\times5+19=119\text{ s},
\]

7 站共 $833$ s，故单纯“全站全频道普查”的基线约为

\[
2183\text{ s}+\text{后续定位/清除时间}.
\]

这只是**最坏保证基线**，高上限程序绝不应机械执行完它。

# 21. 问题 3：覆盖路径优化模型

真正高上限的离线搜索点设计应写成：

\[
\min_{Q_1,\ldots,Q_m,\pi}
L(\pi)
\]

满足

\[
\mathcal D
\subset
\bigcup_{j=1}^mB(Q_j,1000),
\]

机器狗从原点出发，不要求返回原点。

其中 $L(\pi)$ 为访问这些检测点的开放路径长度。

这是一个

\[
\boxed{\text{Covering-Tour Problem}}
\]

可用以下方式求数值改进：

1. 以“中心 + 正六边形”为初始解；
2. 连续优化点坐标；
3. 对访问次序用最近邻 + 2-opt / 模拟退火；
4. 对优化结果用高密度边界与区域采样重新验证 1000 m 覆盖；
5. 最后保留小安全裕量。

论文中应将：

- 正六边形：作为可证明基线；
- 数值优化路径：作为提速结果。

# 23. 问题 3：搜索与定位联合，而非先搜索后定位

最优策略不应机械分成“先发现所有源，再定位所有源”。

机器狗经过新的搜索点时，应顺便对已发现目标进行二次测量，但仅在该次测量信息价值足够高时执行。

例如已有第一次测向线方向 $\theta_1$，当前位置 $Q$ 对定位区域中心产生预计交会角 $\alpha$。

若

\[

较大，则在当前位置多花 5–6 s 可能节省数百米专门横移。

推荐规则：

- 若预计交会角 $\alpha\ge30^\circ$，可考虑顺便测量；
- 若 $60^\circ\le\alpha\le120^\circ$，优先级很高；
- 参数不固定写死，最终由演练测试调优。

# 25. 问题 3：在线动作价值——严格进度与启发式信息增益分层

不建议把“面积减少量”直接解释成真实概率收益，因为题目没有给源位置或误差分布。推荐把在线评分拆成两层。

## 25.1 严格保证进度

对于仍为 UNKNOWN 的频道 $c$，定义其保守位置可行域面积

\[
A_c=\mu(F_c).
\]

在候选点 $Q$ 做一次检测，如果得到 `no_signal`，问题 3 可严格删除

\[
F_c\cap B(Q,1000).
\]

因此定义确定性的覆盖推进量

\[
G_{\rm safe}(Q,c)
=
\frac{\mu(F_c\cap B(Q,1000))}{\mu(F_c)+\varepsilon}.
\]

该量不声称是“检测成功概率”，只衡量最坏保证搜索的推进程度。

## 25.2 粒子层信息增益

在效率层，用可行假设粒子估计不同响应的比例 $\hat p(r|a)$。可定义离散熵

\[
H(\Pi_c)=\log |\Pi_c|
\]

或空间栅格熵，并计算

\[
\operatorname{IG}(a)
=
H(\Pi)-\sum_r\hat p(r|a)H(\Pi|r).
\]

这里的 $\hat p$ 只是**决策代理**，不是题目给定的真实概率分布。

## 25.3 时间归一化评分

候选动作 $a$ 的即时成本为

\[
C(a)=T_{\rm move}(a)+T_{\rm action}(a).
\]

推荐评分

\[
\boxed{
\operatorname{Score}(a)
=
\frac{
\lambda_sG_{\rm safe}
+\lambda_I\operatorname{IG}
+\lambda_L\Delta R_{\rm MEC}
+\lambda_CV_{\rm clear}
}{C(a)+\varepsilon}.
}
\]

其中：

- $G_{\rm safe}$：保证搜索进度；
- $\operatorname{IG}$：粒子层信息增益；
- $\Delta R_{\rm MEC}$：定位半径预计下降；
- $V_{\rm clear}$：可保证清除或高价值试清除收益。

## 25.4 防止“贪心永不完成保证搜索”

仅靠评分可能反复做局部高收益动作而迟迟不完成全域保证，因此增加**保证债务（guarantee debt）**：

- 保存一条有限的兜底覆盖路径；
- 若连续 $K$ 个动作均未减少 UNKNOWN 频道或未增加严格覆盖证书，则强制执行下一个兜底节点；
- 或将未完成保证路径的剩余长度作为滚动代价的一部分。

这样既允许大量机会式绕行，又能保证算法最终回到有限兜底流程。

# 27. Clear-as-Sensing：清除动作的顺序优化

若已知存在的频道 $c$ 的可行域 $F_c$ 不能由一个 20 m 圆覆盖，但能由 $k$ 个圆覆盖：

\[
F_c\subset\bigcup_{j=1}^kB(C_j,20),
\]

则可把 `/clear` 作为主动感知动作。

对一个访问顺序 $\pi$，若真实目标 $G$ 第一次落入第 $j$ 个访问圆，则总代价为

\[
T_\pi(G)
=
L_\pi(j)/5+3(j-1)+5,
\]

其中 $L_\pi(j)$ 是从当前位置到第 $j$ 个圆心为止的累计移动距离。于是可以解小规模鲁棒顺序问题

\[
\boxed{
\pi^*=\arg\min_\pi\max_{G\in F_c}T_\pi(G).
}
\]

对于 $k\le4$ 直接枚举 $k!$ 个顺序即可。

当 $k=2$ 时，先访问较近或最能覆盖高权重粒子的圆心；若第一次失败，严格得到

\[
G\notin B(C_1,20),
\]

再利用原有覆盖关系进入第二圆清除。

最终仍需比较

\[
T_{\rm multi-clear}
\quad\text{与}\quad
T_{\rm extra-bearing},
\]

选择更小者。

# 28. 20 m 圆覆盖定位区域：启发式求解与严格验证必须分开

候选圆心可从以下位置生成：

- MEC 中心；
- 多边形顶点/边中点；
- 两个定位顶点对应的半径 20 m 圆交点；
- 定位区域内部稀疏网格点。

然后用样本点建立小规模集合覆盖，只用于**找候选解**：

\[
\min\sum_jx_j
\]

s.t.

\[
\sum_{j:q_i\in B(C_j,20)}x_j\ge1.
\]

必须特别强调：

\[
\boxed{\text{离散样本被覆盖}\not\Rightarrow\text{整个连续可行域被覆盖}.}
\]

所以在决定“这 $k$ 个 `/clear` 一定能完成”之前，必须做连续几何复核：

\[
\boxed{
F_c\setminus\bigcup_{j=1}^kB(C_j,20)=\varnothing.
}
\]

如果 $F_c$ 是凸多边形/圆弧约束的组合，可用布尔几何库直接求差集；若采用多边形逼近，必须让 $F_c$ 使用**外逼近**、20 m 清除圆使用**内逼近**，这样“差集为空”才是保守安全证书。

# 31.1 问题 3 的完备性（“确保全部清除”的形式化证明）

高上限策略可以很自适应，但最终必须有一个有限兜底，才能真正支撑“确保”。

对任一真实全向源：

1. 若程序提前已经检测到它，则进入定位/清除流程；
2. 若一直未检测到，则保证债务机制最终会完成 7 点覆盖；由于源的接收半径 $\rho\ge1000$，至少一个覆盖点距它不超过 1000 m，因此必返回 `direction` 或 `near`，不可能永远 `no_signal`；
3. 一旦已知源存在，其位置可行域是有界紧集。通常通过主动测向迅速压缩；如果极端几何下迟迟不能达到 $R_{\rm MEC}\le20$，则对当前保守可行域构造**有限个 20 m 圆的连续覆盖**，按第 27 节依次 `/clear`，至少一个必成功；
4. 每个频道最多一个源，频道数有限，因此整个过程有限终止。

故在不考虑接口技术异常的理想规则下，算法满足

\[
\boxed{\text{所有真实全向干扰源最终均会被清除}.}
\]

实际高性能运行几乎不会走到“20 m 圆全覆盖”这一重兜底，它的作用是提供完备性证明。

# 32. 问题 4：为什么问题 3 的 no_signal 逻辑失效

问题 4 存在定向干扰源。

对定向源，在距离满足接收半径的情况下，若检测点位于其发射方向背侧，也会返回 `no_signal`。

因此问题 4 中不能再用

\[
\texttt{no\_signal}
\Rightarrow
G\notin B(Q,1000)
\]

直接排除位置。

这是问题 4 与问题 3 的本质差别。

# 33. 问题 4：定向源的几何模型

设源位置为 $G$，定向方向单位向量为

\[
d(\phi)=
(\cos\phi,\sin\phi).
\]

有效覆盖角度为定向方向两侧各 $90^\circ$，因此检测点 $Q$ 位于有效覆盖范围内当且仅当

\[
\boxed{
d(\phi)^\top(Q-G)\ge0.
}
\]

它本质上是一个以 $G$ 为边界点的闭半平面。

# 34. 问题 4 的核心定理：局部凸包保证

给定一组固定检测点 $\mathcal Q=\{Q_j\}$。对任意源位置 $G$，定义 1000 m 邻近检测点集合

\[
N(G)=\{Q_j:\|Q_j-G\|\le1000\}.
\]

则有

\[
\boxed{
\text{对任意定向方向都至少有一个检测点可见}
\iff
G\in\operatorname{conv}N(G).
}
\]

## 34.1 充分性

若

\[
G=\sum_j\lambda_jQ_j,
\qquad
\lambda_j\ge0,
\quad\sum_j\lambda_j=1,
\]

则

\[
\sum_j\lambda_j(Q_j-G)=0.
\]

若某发射方向 $d$ 使所有邻近点都在背面，则

\[
d^\top(Q_j-G)<0
\]

对所有 $j$ 成立，加权求和将得到 $0<0$，矛盾。因此至少一个邻近点满足

\[
d^\top(Q_j-G)\ge0.
\]

## 34.2 必要性

若 $G\notin\operatorname{conv}N(G)$，由严格分离定理，存在单位方向 $d$ 使

\[
d^\top(Q_j-G)<0,
\qquad\forall Q_j\in N(G).
\]

将源的定向方向取为 $d$，则所有距离上本可接收的检测点均落在背面，从而不能保证发现。

## 34.3 等价的“最大角隙”判据

令所有邻近向量

\[
v_j=Q_j-G
\]

的极角按升序排列，记首尾循环后的最大角隙为 $\Delta_{\max}$。则二维几何中

\[
\boxed{
G\in\operatorname{conv}N(G)
\iff
\Delta_{\max}\le180^\circ,
}
\]

其中若某 $Q_j=G$，可直接视为满足。这给出了一个 $O(m\log m)$ 的快速数值验证器，非常适合优化检测网络后做高密度检查。

## 34.4 Carathéodory 三点证书

由二维 Carathéodory 定理，只要 $G\in\operatorname{conv}N(G)$，就存在至多 3 个邻近检测点使 $G$ 位于它们的凸包内。

定义三点（也允许退化为一、二点）保证核

\[
K_I=
\operatorname{conv}\{Q_i:i\in I\}
\cap
\bigcap_{i\in I}B(Q_i,1000),
\qquad 1\le|I|\le3.
\]

则整个检测网络对任意定向源严格可靠，当且仅当

\[
\boxed{
\mathcal D\subset
\bigcup_{1\le|I|\le3}K_I.
}
\]

这把“连续、任意方向”的问题变成了有限个三点几何区域的覆盖问题，是后面计算机辅助证书的基础。

# 35. 局部凸包定理的意义

问题 4 真正的保证约束不是“每个位置附近至少一个检测点”，而是

\[
\boxed{
\forall G\in\mathcal D,
\quad
G\in\operatorname{conv}\{Q_j:\|Q_j-G\|\le1000\}.
}
\]

这比普通圆覆盖强得多：邻近检测点必须在角度上**包围**源，才能抵抗任意未知 180° 发射半平面。

# 36. 问题 4：纯解析的等边三角网格兜底

构造边长

\[
\boxed{s=990\text{ m}}
\]

的等边三角网格。基向量取

\[
b_1=(s,0),
\qquad
b_2=\left(\frac s2,\frac{\sqrt3s}{2}\right).
\]

采用平移

\[
\boxed{t=0.1b_1+0.1b_2}
\]

并选取**所有与目标圆相交的三角形的全部顶点**作为保证节点。

任意 $G\in\mathcal D$ 必落在某个被选中的三角形 $T$ 中。因为等边三角形的直径就是边长，故对 $T$ 的三个顶点 $V_1,V_2,V_3$ 有

\[
\|G-V_i\|\le990<1000,
\]

且

\[
G\in\operatorname{conv}\{V_1,V_2,V_3\}.
\]

由局部凸包定理，无论源朝向如何，三点中至少一点必能收到信号。这是**完全解析、无需统计假设**的严格保证。

代码枚举两类网格三角形，并用“原点到三角形的最小距离 $\le1800$”判断是否与目标圆相交。对上述 $s,t$ 得到

\[
\boxed{25\text{ 个唯一保证节点}.}
\]

在 $101\times101$ 个平移参数样本的搜索中，观察到的最小节点数也是 25；这只是数值观察，不声称为全局最少。

对这 25 点用“最近邻 + 2-opt”从原点规划开放路线，得到一条约

\[
23.93\text{ km}
\]

的基线路径（不同 2-opt 初值会略有变化）。该网格主要作为**纯解析保险**，不建议默认全走。

# 37. 问题 4：21 点双环高上限保证网络（推荐）

在局部凸包 + 三点证书基础上，可以比 25 点三角网格进一步压缩。

构造 21 个检测点：

### 中心点

\[
C=(0,0).

### 内环 8 点

\[
I_k=1000
\left(\cos45^\circ k,\sin45^\circ k\right),
\qquad k=0,\ldots,7.

### 外环 12 点

\[
O_j=1870
\left(
\cos(15^\circ+30^\circ j),
\sin(15^\circ+30^\circ j)
\right),
\qquad j=0,\ldots,11.
\]

外环正十二边形的内切圆半径为

\[
1870\cos15^\circ\approx1806.28\text{ m},
\]

因此从外部几何上已经包住半径 1800 m 的目标圆。

## 37.1 为什么不能只靠肉眼声称 21 点可靠

21 点网络并不是边长 $<1000$ 的简单三角剖分，因此仅看“环很多”并不能形成严格证明。我们利用第 34.4 节的三点保证核做**保守计算机辅助证书**。

做法：

1. 将每个真实接收圆 $B(Q_i,1000)$ 替换为其**内接 256 边形** $P_i^-\subset B(Q_i,1000)$；
2. 将目标圆扩大到半径 $1806$ m，并用**外切 720 边形** $\mathcal D^+\supset B(0,1806)$；
3. 对全部 $|I|\le3$ 的检测点组合构造

\[
\widetilde K_I=
\operatorname{conv}(Q_I)
\cap\bigcap_{i\in I}P_i^-;
\]

4. 计算

\[
\mathcal D^+
\setminus
\bigcup_I\widetilde K_I.
\]

代码验证该差集为空。

因为

\[
P_i^-\subset B(Q_i,1000)
\]

且

\[
B(0,1800)\subset B(0,1806)\subset\mathcal D^+,
\]

所以这是一个**方向、位置均不采样的保守几何证书**。它不是 Monte Carlo 证据，而是利用多边形内外逼近建立的有限布尔几何覆盖证书。

另外，随机抽取 20 万个目标位置，用最大角隙判据复核，未发现失败点；固定随机种子的一次复核中，观测到的最坏最大角隙约为

\[
179.22^\circ<180^\circ.
\]

随机检验只作交叉检查，不承担证明责任。

## 37.2 路径长度

一个简单且结构清晰的访问顺序是：

1. 原点；
2. 沿内环连续访问 8 点；
3. 从最后一个内环点径向过渡到同角度外环点；
4. 沿外环连续访问 12 点。

对应移动距离

\[
\begin{aligned}
L_{21}
&=1000
+7\cdot2(1000)\sin22.5^\circ
+(1870-1000)\\
&\quad+11\cdot2(1870)\sin15^\circ\\
&\approx17875.38\text{ m}.
\end{aligned}
\]

移动虚拟时间约

\[
3575.08\text{ s}.
\]

相比 25 点网格约 23.93 km 的 2-opt 基线，保证网络的移动长度下降约

\[
\boxed{25.3\%}.
\]

因此问题 4 推荐：

\[
\boxed{\text{21 点双环网络作为正式高性能 guarantee，25 点三角网格作为解析备用}.}
\]

若担心本地几何库版本差异，可先运行本文附带的证书代码；只要保守差集仍为空，再启用 21 点网络。

# 39. 问题 4：离散 MILP 只负责找候选，连续证书负责最终验收

对目标位置样本 $G_i$、方向样本 $\phi_j$、候选检测点 $Q_k$，定义

\[
a_{ijk}=1
\]

当且仅当

\[
\|Q_k-G_i\|\le1000
\]

且

\[
d(\phi_j)^\top(Q_k-G_i)\ge0.
\]

用二元变量 $x_k$ 建立集合覆盖：

\[
\min\sum_kx_k
\]

s.t.

\[
\sum_ka_{ijk}x_k\ge1,
\qquad\forall i,j.
\]

MILP 的作用是筛选低点数候选网络，不承担连续空间的最终证明。得到候选网络后，统一用第 34.4 节三点保证核证书做验收。

# 40. 问题 4：最终推荐“机会式快搜 + 21 点证书补搜”

不应一进入问题 4 就机械走完 21 个保证点。

推荐两层流程：

### 第一层：机会式快搜

- 原点扫描全部频道；
- 沿问题 3 的清除/定位路径，在“几乎不增加移动”的位置顺便扫描 UNKNOWN 频道；
- 利用方向/半径/类型粒子选择高可见、高交会价值的点；
- 每发现一个频道，立即停止它的“存在性扫描”。

### 第二层：证书补搜

对仍 UNKNOWN 的频道，继续访问 21 点网络中尚未完成证书的节点。每个真实定向源由第 37 节保证至少在一个节点返回 `direction` 或 `near`。

已经在其它任务路径上访问过、且坐标与保证节点重合或其测量能够被证书规划器纳入时，不重复访问。

当 `cleared_count==16` 时直接结束；否则必须将所有仍 UNKNOWN 频道推进到“证书完成后仍无信号”，才能标记 `ABSENT`。

# 41. 问题 4：存在性—位置—半径—方向—类型联合可行域

对尚未确定的频道，不能默认“该频道一定存在源”。更严谨的表示是

\[
\boxed{
\mathcal H_c=\{\varnothing\}\cup
\left(
\mathcal D\times[1000,1500]\times[0,2\pi)\times\{O,D\}
\right),
}
\]

其中 $\varnothing$ 表示该频道不存在源；存在源时参数包括：

- $G=(x,y)$：位置；
- $\rho$：有效接收半径；
- $\phi$：定向方向；
- $O/D$：全向/定向类型。

一旦返回 `direction` 或 `near`，立即删除 $\varnothing$ 假设；持续 `no_signal` 则只是削减“存在源”的参数子集，直到保证网络证书完成后该子集为空，才能严格标记 `ABSENT`。

程序实现时不必显式保存一个巨大的连续集合，可以使用：

- 一个严格的 existence 标志/证书状态；
- 位置可行域的保守表示；
- $(x,y,\rho,\phi,\tau)$ 低差异粒子用于效率决策。

# 42. 问题 4：观测更新规则

## 42.1 `direction`

必须满足：

\[
5<\|G-Q\|\le\rho,
\]

并且

\[
|\arg(G-Q)-\theta|\le1^\circ.
\]

若类型为定向，还需

\[
d(\phi)^\top(Q-G)\ge0.
\]

## 42.2 `near`

\[
\|G-Q\|\le5
\]

且若为定向源，还必须位于覆盖半平面。

此时直接清除。

## 42.3 `no_signal`

若源存在，则至少有一个条件失败：

\[
\|G-Q\|>\rho,
\]

或

\[
\tau=D
\text{ 且 }
 d(\phi)^\top(Q-G)<0.
\]

因此 `no_signal` 虽不能直接排除位置，却能联合削减“位置—半径—方向—类型”假设空间。

# 43. 定向方向可以被学习

一旦在位置 $Q$ 成功收到信号，对于一个候选源位置 $G$，定向方向必须满足

\[
d(\phi)^\top(Q-G)\ge0.
\]

等价于

\[
\phi
\in
[\arg(Q-G)-90^\circ,
\arg(Q-G)+90^\circ].
\]

所以一次成功测量已经排除了约一半方向。

如果在一个“可确定距离小于接收半径”的位置却返回 `no_signal`，则对定向源进一步得到

\[
d(\phi)^\top(Q-G)<0,
\]

又能排除另一半方向。

因此问题 4 不能把定向方向永远当作完全未知，它应作为可学习隐藏变量。

# 44. 问题 4：第二/第三检测点的自适应设计

# 49. 路径与测量调度的细节优化

## 49.1 同站频道扫描顺序

任意两个不同频道切换都只需 1 s，因此同一站扫描 $k$ 个不同频道，内部切换次数基本固定为 $k-1$。

可通过让本站最后一个频道与下一站首个频道相同，最多再节省一次切换。

该优化属于次要优化，不应牺牲路径长度。

## 49.2 已发现频道停止“存在性搜索”

一旦频道已返回 `direction` 或 `near`，该频道存在性已确定。

后续只在有定位价值时再次测量，不再参与全域存在性覆盖。

## 49.3 机会式清除

若某可保证清除点距当前路线很近，则立即插入清除动作。

可以定义允许 detour 的阈值

\[
\Delta L_{\rm detour}\le L_0,

$L_0$ 由演练测试调节。

# 50. 终止判定

# 60. 复杂度分析

设：

- 每频道有效测量数不超过 $m$；
- 定位多边形顶点数 $v$；
- 在线候选动作数 $K$；
- 每频道粒子数 $N_p$。

主要复杂度：

- 半平面交：$O(m\log m)$；
- 多边形直径：$O(v)$（旋转卡壳）；
- MEC：期望 $O(v)$ 或小规模枚举；
- 粒子更新：$O(20N_p)$；
- 一步候选评分：$O(KN_p)$；
- 2-opt：小规模 $m\le16$，实际开销极小。

因此程序现实时间通常远小于模拟器允许的 20 分钟，真正约束仍是策略质量而非计算量。

# 67. 本轮数学复核与代码验证结论

## 67.1 问题 1：MEC 与 Jung 界

随机生成 1000 组平面点集，用“枚举二点圆/三点圆”的 MEC 实现检查

\[
\frac D2\le R_{\rm MEC}\le\frac D{\sqrt3}.
\]

结果：0 组违反。样本中观测到

\[
\min R/D=0.5,
\qquad
\max R/D\approx0.57175<1/\sqrt3.
\]

这验证了实现逻辑与理论界一致。

## 67.2 问题 2：局部公式与精确角锥求交

对多组 $r_1,r_2,\alpha$，直接构造两个真实 $\pm1^\circ$ 角锥并做精确几何交，再与第 13 节公式比较。$\alpha\ge30^\circ$ 时相对误差小于约 0.5%；交会角只有 $10^\circ$ 时误差扩大到约 4%，进一步支持“避免小交会角”的策略。

对线段近似 $[5,1500]$ m，在保证接收透镜中做 differential-evolution minimax 搜索：

- 透镜尖点：最坏局部直径约 $123.168$ m；
- 数值最优点：$(824.712,572.776)$，最坏局部直径约 $121.401$ m；
- 改进约 $1.43\%$。

因此透镜尖点应作为**解释性初值**而非最终最优结论。

## 67.3 问题 3：7 点覆盖

解析式给出 $a=1125$ m 时

\[
R_{\rm cov}=999.11066\text{ m}.
\]

另随机生成 50 万个目标圆内位置，计算到 7 个覆盖点的最近距离，未发现超过 1000 m 的点；随机样本最大值约 $998.17$ m。由于随机样本不会刚好击中解析最坏点，最终保证仍以第 20 节解析证明为准。

## 67.4 问题 4：25 点解析网格

取

\[
s=990,\qquad t=0.1b_1+0.1b_2,
\]

代码枚举所有与半径 1800 m 圆相交的等边三角形，共得到 25 个唯一顶点。

## 67.5 问题 4：21 点双环证书

对

\[
\{C\}\cup\{I_0,\ldots,I_7\}\cup\{O_0,\ldots,O_{11}\}
\]

建立 Carathéodory 三点保证核。

保守验证使用：

- 接收圆半径 1000 m 的**内接 256 边形**；
- 目标半径扩张到 1806 m 后的**外切 720 边形**；
- 所有至多 3 点组合的凸包与内接接收多边形交；
- 对其并集与扩张目标多边形做差集。

得到差集为空。继续将目标扩张到 $1806.25$ m 仍通过，而约 $1806.28$ m 开始出现极小缺口，与外环正十二边形内切半径

\[
1870\cos15^\circ\approx1806.2813

高度吻合。

因此 21 点网络具有约 6 m 的目标半径证书裕量，足以覆盖数值布尔运算的常规浮点误差量级。

import math

R = 1800.0

def cover_radius_7(a):

        a / math.sqrt(3),
        math.sqrt(R*R + a*a - math.sqrt(3)*R*a)

a_min = (

## 68.2 问题 2：两站局部交会直径

import math

DELTA = math.radians(1)

def d_local(r1, r2, alpha_deg):
    a = math.radians(alpha_deg)
    return (
        2 * math.tan(DELTA)
        * math.sqrt(
            r1*r1 + r2*r2
            + 2*r1*r2*abs(math.cos(a))
        )
        / abs(math.sin(a))
    )

print(d_local(1000, 1000, 90)) # 49.370379...

## 68.3 问题 4：最大角隙局部凸包判据

```python
import math

def directional_guaranteed(G, Qs, r=1000.0, eps=1e-10):
    gx, gy = G
    ang = []
    for qx, qy in Qs:
        dx, dy = qx-gx, qy-gy
        d = math.hypot(dx, dy)
        if d <= eps:          # 检测点与源重合
            return True
        if d <= r + eps:
            ang.append(math.atan2(dy, dx) % (2*math.pi))

    if len(ang) < 2:
        return False

    ang.sort()
    gaps = [ang[i+1]-ang[i] for i in range(len(ang)-1)]
    gaps.append(2*math.pi-ang[-1]+ang[0])
    return max(gaps) <= math.pi + eps
```

import math

def ring(radius, n, offset_deg=0.0):
    return [
        (
            radius*math.cos(math.radians(offset_deg+360*k/n)),
            radius*math.sin(math.radians(offset_deg+360*k/n)),
        )
        for k in range(n)
    ]

Q21 = (

    + ring(1000.0, 8, 0.0)

## 68.5 Carathéodory 三点核保守证书（Shapely）

```python
import itertools
import math
from shapely.geometry import Polygon
from shapely.ops import unary_union


def regular_polygon(center, radius, n, circumscribed=False):
    cx, cy = center
    rr = radius / math.cos(math.pi/n) if circumscribed else radius
    return Polygon([
        (
            cx + rr*math.cos(2*math.pi*k/n),
            cy + rr*math.sin(2*math.pi*k/n),
        )
        for k in range(n)
    ])

# 内逼近接收圆：一定落在真实 1000 m 圆内
recv_poly = [regular_polygon(q, 1000.0, 256, False) for q in Q21]

cores = []
for I in itertools.combinations(range(len(Q21)), 3):
    tri = Polygon([Q21[i] for i in I])
    if tri.area < 1e-9:
        continue
    g = tri
    for i in I:
        g = g.intersection(recv_poly[i])
    if not g.is_empty:
        cores.append(g)

U = unary_union(cores)

# 外逼近目标圆，并额外把半径扩大到 1806 m
D_plus = regular_polygon((0.0, 0.0), 1806.0, 720, True)
residual = D_plus.difference(U)

print(residual.area)  # 本轮验证为 0.0
```

严格实现时可把一、二点退化组合也加入；对本 21 点网络，三点核已经覆盖目标区域。

# 69. 本地官方模拟器测试时的建议实验顺序

为了避免“模型正确但参数没调好”，建议本地按以下顺序跑演练：

1. **几何单元测试**：先运行第 68 节，确认本机浮点/几何库得到一致结果；
2. **问题 3 保证基线**：固定 7 点 + 普通交会，确认清除率先稳定到 100%；
3. **问题 3 高性能版**：依次开启机会式 UNKNOWN 扫描、minimax 选点、2-opt、Clear-as-Sensing，做消融；
4. **问题 4 25 点解析备用**：先确认最保守策略能稳定清干净；
5. **问题 4 21 点证书网络**：替换保证层，观察平均时间下降；
6. 最后再启用方向粒子、滚动时域等复杂模块。

正式测试前最重要的不是把所有高级模块都打开，而是保证：

\[
\boxed{
\text{全清除率}=100\%
\quad\text{且}\quad
\text{高级模块确实在演练统计上降低平均时间}.}
\]

如果某个复杂模块让均值略降、但方差或失败率上升，应关闭它。竞赛正式测试只有 3 次，稳定性优先于微小的期望收益。
