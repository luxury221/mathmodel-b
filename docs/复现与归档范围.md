# 复现与归档范围

## 环境

原实验使用Python 3.12.14。`requirements-offline.txt`记录当前核验过的主要离线计算库版本；`requirements.in`和带哈希的`requirements.lock.txt`保存完整环境定义。这里没有复制虚拟环境或安装包。

Windows本地准备示例：

```powershell
cd D:\数模B题\mathmodel-b
. .\scripts\env.ps1
py -3.12 -m venv .venv
& $PythonExe -m pip install -r requirements-offline.txt
```

`env.ps1`将TEMP、TMP、pip/uv、Jupyter、Matplotlib等缓存和运行目录放在D盘。仓库上传不负责安装或运行官方模拟器。

## 检查归档是否自洽

```powershell
& $PythonExe scripts\verify_published_results.py --replay-offline
& $PythonExe -m pytest tests -q
```

第一条命令检查精确复制文件的SHA-256、官方匿名表格的数值/计费分解、两题各32案例的本地成对均值，并回放全部128条本地轨迹。它**不会连接官方服务，也不会重新认证未上传的原始官方响应**。

复现与回放均使用历史验证器的 `EvaluationWorld`，保留压力场景的空间相关测角误差，不能用开发环境的默认噪声替代。指定历史场景文件时，默认同时包含 `boundary_noise` 压力场景，不会静默排除这8例。

仓库通过`.gitattributes`禁用自动行尾转换，以保持冻结源码和证据文件的字节级哈希；不要先格式化历史文件再做一致性核验。

默认pytest只收集`tests/`的归档检查。历史试验目录中有独立测试与路径约定，不能把所有阶段不加区分地作为同一套模块收集。

## 重跑当前本地策略

```powershell
& $PythonExe scripts\run_offline_baselines.py --problem all --counts 13 --output D:\数模B题\mathmodel-b\outputs\offline_dev
```

也可明确重跑一份已归档的历史留出场景：

```powershell
& $PythonExe scripts\run_offline_baselines.py --problem q3 --case-file reports\scan_validation_v13\validation_20260911_235435\scenes_evaluator_only.json --output D:\数模B题\mathmodel-b\outputs\q3_historical_replay
```

输出目录必须新建，避免覆盖历史证据。`--limit 1`仅用于安装/执行通路冒烟检查，生成的子集结果不能代表完整验证。运行使用的始终是冻结Q3 v13与Q4 v11，**不会运行v48草稿或任何官方PRACTICE/FORMAL客户端**。

## 内容和限制

已纳入：研究代码、阶段协议/发现、当前策略依赖、合成评价场景、双策略本地原始记录与轨迹、精选几何证书、匿名官方数值表、原始方案设计存档。

未纳入：官方赛题PDF/附件、官方模拟器、运行时/缓存、原始官方日志/截图、队伍与会话标识、登录凭据、嵌套Git元数据、下载的第三方论文副本。

部分历史研究入口要求本地完整档案中的其他批次，不能保证每个旧`run_*.py`在精选归档下原样重跑；推荐先使用本页的独立复现入口。`source_copy_manifest.json`明确记录本次精确复制范围，不将未上传资料伪装成已公开证据。

原始建模方案可能包含后续已修正或未验证的建议；当前状态以README和日期化数据摘要为准。v48只有协议和部分源码，没有本阶段验证记录。
