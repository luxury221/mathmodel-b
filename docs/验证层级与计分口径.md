# 验证层级与计分口径

日期：2026-09-12。阅读任何历史报告时，应同时看“数据来自哪里”“评价了什么”“是否全清”，不能只比较一个数字。

| 层级 | 数据/运行方式 | 可以支持什么 | 不能支持什么 |
|---|---|---|---|
| 本地几何与单元测试 | 人工几何、布尔模型、精确有理证书、固定小例子 | 被测逻辑、覆盖证书或数值实现正确性 | 官方成绩、整任务提速 |
| 本地开发模拟 | 自建公开规则近似环境、已用开发种子 | 机制筛选、消融、失败诊断 | 官方平台效果、独立泛化结论 |
| 本地独立验证 | 在候选冻结后使用的历史留出/压力集 | 在该组本地场景上的成对效果和全清率 | 官方演练分数；再次重跑不能算新独立验证 |
| 本地HTTP兼容/回放 | 自建接口或基于记录的响应回放 | 客户端接口、动作序列、计时一致性 | 真实官方调用；HTTP形式不使模拟变成官方测试 |
| 官方演练 PRACTICE | 真实官方模拟器演练模式、保留原始执行证据 | 对应已完成演练案例的官方结果 | 正式测试结果、其他未知案例表现 |
| 正式测试 FORMAL | 官方正式模式 | 对应正式测试结果 | 不得由演练或本地结果推算 |

## 指标定义

设第i个案例实际源数为N_i，完整任务虚拟时间为T_i，共K个案例，则报告：

`mean_seconds_per_source = sum(T_i / N_i) / K`

不是 `sum(T_i) / sum(N_i)`。只有全部案例完整成功，才给出该候选有效均值；失败不得从集合里删除。

费用核算：移动距离/5；每次测量5秒；仅测量操作在切换接收频道时另计1秒；成功光学清除5秒，失败3秒。**光学清除不会切换接收机频道。**

官方匿名表保留原始审计的 `rounding_residual_seconds`，即任务总时间减去费用分项之和。本批次最大绝对残差约2.225微秒；核验要求“分项之和+已记录残差”与总时间在1e-8秒内一致，并另检查残差不超过按动作六位小数舍入计算的保守界 `(测量次数+成功清除次数+失败清除次数)*0.5e-6+1e-6` 秒。此项只解释数值舍入，未调整任务时间或成绩。

完整任务包括最后一次成功清除之后，为确认没有剩余源而发生的真实操作。不得只报告首次发现、最后清除、局部定位阶段或选定有利源数的耗时。
